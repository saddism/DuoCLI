远程连接指南

1. 同一 Wi-Fi，马上能用

电脑打开 DuoCLI 后，本地服务会自动在 9800 端口就绪，不用再装别的软件。

  1. 手机和电脑连同一个 Wi-Fi
  2. 手机浏览器打开下面的局域网地址
  3. 粘贴 Token，点「连接终端」
局域网 启动后自动显示

地址和 Token 也在左侧「手机远程同步」卡片里。点眼睛可查看 Token。

2. 固定公网地址，出门也能连

局域网只能在家里用。要在外面用手机连，需要一个你自己的固定域名，通过 Cloudflare Tunnel 转到本机 9800。不用自己买云服务器，也不用开端口。

    1. 安装 cloudflared
      brew install cloudflared
    2. 登录 Cloudflare，并创建一条隧道
      cloudflared tunnel login
      cloudflared tunnel create duocli

      登录后会得到隧道 ID，凭证一般在 ~/.cloudflared/<隧道ID>.json。域名要在 Cloudflare 里指到这条隧道。

    3. 生成本机配置文件，把隧道名、域名、凭证路径改成你自己的

      配置路径将在这里显示

    4. 保存文件后回到 DuoCLI 点「重试」，侧栏地址应变为 https://你的域名

    连不上时

    • 先确认电脑 DuoCLI 还在运行。关掉窗口一般还能连，完全退出应用后本地服务会停。
    • 局域网打不开：确认同一 Wi-Fi，并让防火墙放行 9800 端口。
    • 提示 Token 错误：从侧栏点眼睛复制，不要手打。
    • 公网打不开：配置文件里不能还留着 YOUR_TUNNEL_NAME、duocli.example.com 这类占位符。
