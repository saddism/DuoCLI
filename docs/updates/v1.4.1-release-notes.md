# DuoCLI v1.4.1 — 滚出去很远，也还记得自己在说什么

> **对话滚到几百行以后，最容易忘的不是 Agent 在干什么，而是你刚才让它干什么。这一版把那句话钉在顶上，也让文件、下载和已关闭会话更听话。**
>
> *After a long scroll, the first thing you lose is not the agent's output — it is the request that started it. This release pins that sentence to the top, and makes files, downloads, and closed sessions behave the way you expect.*

---

## 中文

### 滚屏很远以后，工作还在不在？

AI CLI 的对话一旦铺开，终端里全是工具调用、补丁和确认框。你往上翻两屏，常常已经想不起来自己最初说了什么。

手机上更明显：窄屏、键盘、来回切会话，顶上一句「当前在干什么」比再找一遍历史有用得多。

v1.4.1 先把这件事做实，再顺手修掉几个会让人觉得「工具不够懂我」的细节。

### 最近在说：顶栏钉住你刚说的话

桌面终端和手机网页的对话区顶部，现在都会留下你**最近说过的那句话**：

- 默认只展示前 200 字，长内容可以点「更多」展开；
- `y` / `n` / `好` 这类确认不会顶掉真正的任务；
- 「滚动到这里」会回到这句话所在的消息块，并尽量停在**标题栏顶部**，方便接着往下看 Agent 的回复；
- 窗口缩放、折行、CLI 画的框线不会再把落点算偏；
- 这句话由桌面和网页共用：电脑上发的，手机打开同一会话就能看见。

刷新手机页面、重启桌面窗口后，进到那个会话就能看到。

### 文件不想用默认应用？自己选

桌面端文件树和终端链接现在支持「其他应用程序…」。

系统会列出能打开该文件的应用，也可以再走一次系统选择框。不再只能默认打开，或只能塞进事先指定的编辑器。

### 已关闭会话，按「最后干活」排

以前已关闭列表更像「谁最后被点了关闭」。真正有用的顺序其实是：哪一段工作最近还在动。

现在列表按最后活动时间从新到旧排；旧记录会尽量用本地 CLI 会话文件补上时间。你要恢复的，通常就在最上面。

### 下载就是下载，不要变成网页

手机端保存 ZIP、视频或中文文件名时，Safari / 微信有时会把它当成网页打开，最后存成 `xxx.mp4.html`。

这一版下载统一按附件处理：

- 中文文件名用标准 `Content-Disposition` 带出去；
- 内容类型固定为附件流，避免被当成 HTML；
- 预览里的图片、音视频和网页在离开时会停掉，不再后台继续播。

### 桌面工作区，一眼能看出是哪个项目

会话卡片和 Pane 标题栏会带上项目名；窗口标题也按「会话 / 目录 / CLI」排好。AI 配置收进侧边栏设置，不再占掉一整块标签页。

终端滚动跟随也更稳：你正在往回看历史时，新输出不会把阅读位置抢走。

### 升级后，先试这几件事

1. 在桌面给 Agent 发一句稍长的任务，再用手机打开同一会话，看顶栏「最近在说」。
2. 把终端滚到很下面，点「滚动到这里」，确认停在那条消息的标题栏顶。
3. 在文件树上对一个文件选「其他应用程序…」。
4. 从手机保存一个中文名的 ZIP 或视频，确认下载名没有变成 `.html`。

**一句话介绍：DuoCLI——滚多远都还记得你在说什么，文件和会话也按你真正的工作顺序来。**

## English

### The first thing a long transcript steals is your own request

Once an AI CLI conversation opens up, the screen fills with tool calls, patches, and confirmation boxes. Scroll two screens and the original ask is already gone.

On a phone it is worse. The most useful line is not another page of history — it is a pinned reminder of what you asked for.

Version 1.4.1 starts there, then tightens a few file and session edges that used to feel slightly off.

### “Last said” stays at the top

Desktop terminals and the mobile web view now keep your **most recent real prompt** above the conversation:

- The first 200 characters are shown by default, with More / Collapse for longer text;
- One-letter confirmations such as `y` / `n` do not replace the actual task;
- **Jump here** returns to that message block and lands on the **title-bar top**, so you can read the reply downward;
- Window resize, wrapping, and CLI box drawing no longer send the jump to the wrong row;
- Desktop and phone share the same sentence: send it on the computer, open the session on your phone, and it is already there.

### Open files with the app you actually want

The desktop file tree and terminal file links now include **Open with…**. DuoCLI lists apps that can open the file, or you can use the system picker. You are no longer limited to the default handler or one preselected editor.

### Closed sessions follow last activity

The closed-session list used to feel ordered by “who was dismissed last.” The useful order is “which piece of work moved last.”

Sessions now sort by last activity. Older records backfill a timestamp from local CLI session files when possible, so the one you want to resume is usually at the top.

### A download should stay a download

Saving a ZIP, video, or Chinese filename on a phone could be treated as a web page, then stored as `xxx.mp4.html`.

Downloads are now forced as attachments: UTF-8 filenames travel correctly, the payload is not sniffed as HTML, and media or HTML previews stop when you leave the page.

### The desktop board names the project

Session cards and pane headers show the project folder. The window title is arranged as session / directory / CLI. AI settings live behind the sidebar gear instead of occupying a whole tab.

Terminal follow-scroll is also stricter: new output does not yank the viewport while you are reading history.

**DuoCLI keeps the sentence you are working on in sight — and keeps files and sessions in the order your work actually happened.**
