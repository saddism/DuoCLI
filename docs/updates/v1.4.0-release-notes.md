# DuoCLI v1.4.0 — 离开电脑，工作也接得住

> **从“手机能连上终端”，走到“整段工作真正接得住”。草稿、命令、计划、文件和触控，都留在它们该在的会话里。**
>
> *Step away without dropping the thread. DuoCLI now keeps drafts, commands, automation, files, and device control attached to the right session across desktop and phone.*

## 中文

### 远程开发，最怕的不是断线

真正让人不敢离开电脑的，往往不是手机偶尔断一次线。

是你在会话 A 写了一大段要求，切去会话 B 看结果，再回来发现草稿没了；是网络闪了一下，你不确定刚才那条命令到底有没有执行，于是再点一次，结果跑了两遍；是上传文件时顺手切了会话，文件路径却落进了另一个项目；是你以为“计划继续”会一直运行，实际桌面窗口一失去活跃状态，计时也跟着停了。

v1.4.0 处理的就是这些不显眼、却会让人失去信任的瞬间。

### 每个会话，记住自己的话

手机端现在按会话保存草稿。你可以在 Claude 里写一半，切去 Codex 看测试，再回到 Claude 接着写；刷新页面、网络重连或暂时离开，也不会把不同会话的内容混在一起。

发送也更可靠：

- 每次提交都有稳定 ID，确认响应丢失时沿用原提交继续查询或重试；
- 同一条命令不会因为双击、HTTP 重试或 WebSocket 重连而执行两次；
- 发送过程中继续编辑的新文字会留在输入框里；
- 网络未就绪时保留草稿，并明确告诉你当前不能发送。

上传文件也绑定到选择文件时的会话。即使上传过程中切到另一个项目，文件和回填路径仍会回到原来的草稿。

### 计划继续跑，不再依赖窗口一直醒着

“计划设置”从桌面渲染层迁入了主进程。

这意味着定时继续、多条命令、命令间隔、循环次数和自动同意都会持久化运行。桌面窗口隐藏、渲染器暂时不可用，计划仍由主进程接管；你手动输入后，下一轮也会按规则顺延，不会和你抢终端。

它更像一个真正的后台任务，而不是挂在界面上的倒计时。

### 快捷命令，桌面和手机终于是同一份

快捷命令现在保存在本机服务端，桌面和手机共享更新：

- 在一端添加或删除，另一端会同步；
- 每个桌面终端 Pane 都有独立输入区和自己的草稿；
- 点击快捷命令只会插入到光标位置，不会突然执行；
- 只有你点击发送后，命令才进入终端。

高频操作更快，最后一次确认仍在你手里。

### 看得到文件，就能打开，也能拿走

AI CLI 输出的文件路径经常被手机窄屏拆成两三行，中文目录、括号引用和带空格路径更容易点不中。v1.4.0 重做了逻辑行与链接命中：

- 跨行的 Markdown、TypeScript、Vue、Python、JSON、图片和压缩包路径可重新拼接；
- 中文说明里的括号文件引用仍能准确识别；
- HTML、PDF、图片、音视频和更多文本格式可直接预览；
- ZIP、Office、设计源文件、安装包、数据库和常见工作文件可直接下载；
- 下载始终限制在当前工作目录内，服务端继续校验路径边界。

AI 说“结果在这里”，你现在真的可以直接点开它。

### 手机端，从终端页面变成一块工作台

手机工作流这次也重新整理了一遍：

- 点击通知直接进入对应会话；
- 标题栏可快速切换近期会话；
- 浏览器返回键先退出当前工作层级，不会莫名离开页面；
- 会话卡片支持置顶与明确的关闭确认；
- 关键触摸按钮统一扩大，减少横向寻找和误触；
- 网页快捷键栏新增 **Option + ↑**，中间的加号只表示组合；
- 桌面浏览器横屏访问 PWA 时，可以同时看到左侧会话、中间终端和右侧 Android 画面。

你不需要把手机当成缩小版电脑。DuoCLI 只把远程时真正需要的控制放到拇指够得到的位置。

### Android 远程控制：按下去，就应该算数

这次不仅调整了画面，也补强了整条输入链路：

- 首次触摸会等待控制权交接，不再静默丢掉；
- 长按在手指抬起前就会发送按下事件，拖拽保留真实持续时间；
- 手指拖出画面边缘后仍能正确结束，不留下“幽灵触点”；
- 断线、切设备和旧确认不会把输入串到新连接；
- 桌面与手机不会在镜像就绪时反复争抢控制权；
- 新增返回、主屏和菜单导航键；
- 实时流不可用时，JPEG/截图回退仍保持正确坐标与手势语义。

远程控制不该让你猜“这一点到底点到了没有”。

### 桌面工作区，也更像一张真正的工作台

Pane 布局现在是全局的。切换工作目录不会把当前分屏拆掉，你可以把不同项目、不同 CLI、文件预览和 Android 画面放在同一块工作区里。拖动 Pane 标题即可交换位置。

终端细节也同步改善：复制可正确合并视觉换行，滚动历史时新输出不会抢走阅读位置，切回会话会回到最新内容；随机主题会自动选择可读前景色，亮色和深色背景都更清楚。

### 新增 DSH 支持

内置预设新增 DSH。DuoCLI 会识别 dsh-tui / dsh 命令，发现当前可用的本地 host，替换失效的旧地址，并处理需要鉴权的连接；恢复会话时也会生成对应命令。

如果本机 DSH host 协议与当前 dsh-tui 版本不兼容，终端会给出明确说明，而不是让连接停在一个看不懂的错误上。

### 长时间运行，心里更有底

- 连接使用代次隔离，旧 WebSocket 的迟到消息不会写进新会话；
- 请求超时覆盖响应体读取，半开连接会主动结束并重试；
- 从后台回到前台先做短探活，再决定是否重连；
- 终端重建、尺寸确认和弱网重连会保留正在阅读的历史位置；
- 上下文捕获缓存限制为 2 MB，并在会话退出时释放。

## English

### Remote access is easy. Trustworthy remote work is harder.

A dropped connection is annoying. A lost draft, a duplicated command, or a file uploaded into the wrong session is dangerous.

Version 1.4.0 focuses on the details that decide whether you can actually trust a remote workflow. Every draft stays with its session. Every submission has a stable identity. Scheduled work runs in the main process. Uploads keep their original destination. Reconnects preserve the history you were reading.

### Session-bound drafts and idempotent submissions

Start a long instruction in Claude, check a Codex session, and come back without losing a word. Drafts survive session switches, reloads, and reconnects.

Submissions now reuse the same ID when delivery confirmation is uncertain, preventing double execution across repeated taps, HTTP fallback, and WebSocket retries. Text you type while a send is pending remains in the editor, and offline states keep the draft instead of pretending it was sent.

Uploads are pinned to the session that selected them, so changing sessions mid-upload cannot send the resulting path to another project.

### Automation that lives beyond the renderer

Scheduled continuation now runs in the Electron main process. Multi-command cycles, command spacing, loop limits, delayed starts, and automatic approval persist even when the desktop window is hidden or the renderer is unavailable.

Manual input postpones the next scheduled cycle, so background automation stays out of your way when you take control.

### One quick-command library across desktop and phone

Quick commands now live in the local host service and sync across clients. Each desktop terminal pane has its own composer and draft.

Clicking a quick command inserts it at the cursor. It does not execute until you explicitly press Send. The workflow is faster without turning a shortcut into an accidental command.

### Files that remain usable on a narrow terminal

DuoCLI now reconstructs file paths split across terminal rows, including Chinese directories, spaces, parentheses, and common source or artifact formats.

Preview HTML, PDF, images, media, and text directly. Download archives, Office documents, design files, installers, databases, and other work artifacts through a workspace-bounded server route.

When an agent points to an artifact, the path behaves like an artifact.

### A mobile workspace instead of a shrunken desktop

Notifications open the right session. The header offers quick session switching. Browser Back follows the current workflow. Touch targets are larger, session cards can be pinned, and closing a session requires a clear confirmation.

The web shortcut bar now includes **Option + Up** as one terminal combination. On a desktop-width browser, the PWA can show sessions, the active terminal, and the Android device side by side.

### Android control that survives real gestures

The control path now preserves first taps during ownership transfer, sends long-press DOWN events while the finger is still held, keeps drag duration and final coordinates, and releases contacts safely at the screen edge.

Stale sockets and acknowledgements cannot inject input into a replacement connection. Desktop and mobile no longer steal control from each other when a mirror becomes ready. Back, Home, and Recents controls are available beside the device view, with consistent behavior on live video and fallback images.

### One pane board across projects

The desktop pane layout is now global. Changing the current project no longer tears down the board, so terminals, files, and devices from different projects can stay visible together. Drag pane headers to swap positions.

Selection copy, scroll-follow behavior, session switching, and terminal color contrast have also been tightened up.

### DSH joins the workspace

DuoCLI now includes a DSH preset, detects dsh and dsh-tui commands, resolves a live local host, replaces stale host addresses, handles authenticated hosts, and builds resume commands.

Protocol mismatches produce a useful explanation instead of an opaque connection failure.

### Built and tested

Built with Node.js 20:

- **185/185** unit tests
- **63/63** mobile page end-to-end checks
- **18/18** real remote-protocol end-to-end checks
- Desktop copy, scroll, quick-command, and remaining browser scenarios all green

**DuoCLI keeps the AI CLIs working on your computer while you carry the full thread of control with you.**
