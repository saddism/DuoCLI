# DuoCLI v1.2.1 — 一个窗口，随手管理常用的 AI CLI

> **不在多个终端窗口之间找 AI。打开 DuoCLI，选一个工作目录，剩下的交给你熟悉的 CLI。**

---

## 中文

### 这次更新，解决了一个很不应该的限制

DuoCLI 原本把「新建终端」和「新增分屏」混在了一起：当桌面上已经排满 4 个 Pane 时，继续新建会话就像撞上了一堵墙。

但普通会话和分屏，本来就应该是两件事。

现在的规则更简单：

| 你要做什么 | DuoCLI 怎么处理 |
|---|---|
| 新建一个普通终端 | 继续创建，保留在右侧会话列表，并显示在当前焦点区域 |
| 在多个终端之间切换 | 像切换标签一样复用当前焦点区域，不会偷偷增加分屏 |
| 同时对照多个终端 | 先点击 Pane 的「右拆分」或「下拆分」，再选择要放入的会话 |
| 分屏排满以后继续新建 | 不会被 4 个可见分屏挡住，普通会话仍可继续添加 |

分屏最多保留 4 个，是为了让 Claude、Codex、Kimi 等终端在一个桌面里仍然看得清、点得准。会话数量和可见分屏数量不再互相绑死：**想多开就多开，需要并行时再分屏。**

### 为什么 DuoCLI 要这样设计？

你不应该为了同时使用多个 AI 编程工具，记住一排一模一样的终端窗口，也不应该为了开第 5 个任务，先关闭前面某个分屏。

DuoCLI 做的事情很朴素：

- 把 Claude Code、Codex、Gemini、Kimi、Cursor、Kiro、QoderCN、OpenCode、Antigravity 等 CLI 放进一个轻量桌面
- 记住每个会话的工作目录、标题、颜色和运行状态
- 用会话列表快速切换，不让你在多个窗口之间来回寻找
- 需要并行查看时，用最多 4 个清晰分屏把重要任务放在一起
- 终端太多时，仍然可以继续创建普通会话，不被分屏布局卡住

一句话：**DuoCLI 不替你改变工作习惯，只把那些重复、琐碎、容易找错的操作收起来。**

### AI 配置，现在也说得更明白

右上角入口改为「AI 配置」，并在面板中明确说明用途：AI 用于整理会话历史，并根据你发送给终端的内容自动生成对话标题；它不参与终端命令执行。

这样你可以知道 API 配置为什么存在，也能更放心地决定是否启用它。

### 启动和恢复更稳

修复了一个会让历史 Pane 布局在启动阶段打断渲染器的问题。即使之前保存过已经结束的终端分屏，DuoCLI 也会先正常启动，再清理失效布局，不会再出现「窗口已经打开，却无法新建终端」的情况。

### 升级后你会看到什么

1. 更新并重新启动 DuoCLI。
2. 像以前一样点击「新建终端」；不需要先整理已有分屏。
3. 想并行对照时，使用每个 Pane 标题栏上的拆分按钮。
4. 右侧会话列表始终是所有普通会话的入口。

### 一句话介绍

**DuoCLI：一个轻量的桌面，把你常用的 AI CLI 放在一起；少开几个窗口，少记几条命令，专心把事情做完。**

## English

### This update removes an unnecessary wall

DuoCLI used to treat “new terminal” and “new split pane” as the same action. Once four panes filled the workspace, creating the next session could feel blocked.

Those are different concepts. v1.2.1 separates them:

- New terminals continue to open and remain available in the session list.
- Switching sessions behaves like switching tabs and reuses the focused area.
- Splitting is explicit: use a pane’s split controls when you actually want side-by-side work.
- Four visible panes remain the practical readability limit, but that limit no longer limits the number of ordinary sessions you can create.

Run as many ordinary sessions as your machine can reasonably handle; keep the important ones side by side when comparison helps.

### One quiet desktop for your AI CLI workflow

DuoCLI brings Claude Code, Codex, Gemini, Kimi, Cursor, Kiro, QoderCN, OpenCode, Antigravity, and other CLI tools into one lightweight workspace.

It remembers the working directory, title, color, and activity state for each session, so you can stop hunting through identical terminal windows. When parallel visibility matters, use up to four readable panes. When it does not, simply keep creating and switching ordinary sessions.

### AI configuration is clearer

The sidebar entry is now called “AI Configuration” and explains its purpose: the configured AI helps organize session history and automatically generate conversation titles from the input you send to the terminal. It does not execute terminal commands.

### Safer startup and recovery

Fixed a renderer initialization issue that could interrupt startup when an old workspace contained panes for already-ended terminals. DuoCLI now starts normally and cleans stale layouts afterward, so an old split arrangement cannot prevent new terminal creation.

### Upgrade

1. Update and restart DuoCLI.
2. Create ordinary sessions as usual; existing panes do not need to be rearranged first.
3. Use the split buttons only when you want simultaneous side-by-side views.
4. Use the session list as the single place to find every ordinary session.

**DuoCLI: one lightweight desktop for the AI CLI tools you already use. Fewer windows, fewer commands to remember, more time to finish the work.**
