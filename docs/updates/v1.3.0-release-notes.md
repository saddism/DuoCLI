> **换一个 AI 工具，不换一种工作方式。DuoCLI 现在能把整段对话打包带走，也能让手机上的每一次点击，都落在它该落的地方。**
>
> *Switch tools without switching gears. DuoCLI now carries your whole conversation forward — and makes every tap on your phone land exactly where you meant it to.*

## 中文

### 你的痛点，我们都懂

用过多个 AI 编程 CLI 的人，都有过这样的瞬间：Claude 把功能写了一半，你想交给 Codex 收尾——于是你复制粘贴、翻历史、重新描述需求，像在给一个新同事做三个小时交接。

或者：人已经躺在沙发上，手机连上了家里电脑的终端，看到一个想点的地方——手指却像隔着一层玻璃，怎么点都不对。

v1.3.0 就是冲着这两个瞬间来的。

### 手机看 Android：看得见，就点得着

手机端镜像画面这次不再只是“能看”。我们重写了命中映射：

- **所见即所得**：视频流和截图两种画面下，你看到的光标位置就是设备上会触发的位置；
- **够得着的点击目标**：就算画面里的小按钮只有 16px，实际命中区域也会放大，不再“差一点就点到”；
- **滚动交给浏览器**：纵向滚动、双指手势都留在触屏习惯里，横向内容才交给设备，误触大幅减少。

### 跨 Agent 上下文转移：换工具，不丢记忆

桌面端每个关闭的会话，只要有过对话，都会在侧边栏出现一个「导出」入口：

- 一键导出该会话的整段问答历史（自动识别各家 CLI 的输出格式）；
- 在浏览器里打开一份清爽的上下文查看器，user 与 AI 消息一目了然；
- 导出的 JSON 可以直接拖进 Claude Code、Codex、Cursor 等任何一家 CLI，继续你未完成的事。

**不再需要把几十行对话复制来复制去。**

### 支持的 CLI 更多，恢复也更聪明

- **新增 Qoder（qodercli）全自动预设**，同一产品线的多个命令名会被自动识别；
- 会话恢复适配全面升级：Claude Code、Codex、Gemini、Kimi、Cursor、Antigravity、OpenCode、Kiro、Qoder… 的 resume 参数都能被正确捕获——包括各家 headless 模式输出的 JSON 会话 ID；
- 启动后后台预热 CLI 探测：手机端打开「新建会话」不再因为逐个检查未安装的 CLI 而卡住。

### 移动端体验升级

- **计划设置面板**：开启/关闭、自动同意权限、按分钟设定提醒间隔，都放进一个可视化弹窗；
- **项目文件浏览**：目录树 + 类型筛选，文档、媒体、项目文件一键归位；
- **Android 画面更顺手**：实时画面、设备截图入口更清晰；
- **配色更自由**：一批新的终端主题色任你选，桌面手机同款审美。

### 远程连接，更稳也更省心

- **Cloudflare 常驻守护**：远程服务不再因为 502 反复断连，守护进程会自动探测并拉起隧道；
- **关窗不断连**：关掉 DuoCLI 窗口，远程服务照常在线，手机端随时回来；
- **Token 可直接编辑保存**：远程访问 Token 不再只是“看一眼”，桌面端支持编辑并持久保存。

### 一键启动，重构成你真正会用的样子

双击启动器现在会替你做好三件事：**拉取最新源码 → 停掉旧的打包版 → 用最新代码启动**。再也不会出现“明明更新了，跑的还是老版本”的尴尬。

### 质量

单元测试 **104/104** 通过，覆盖会话恢复、镜像协议、PTY 环境、文件预览与移动端回归。

### 升级

1. 更新 DuoCLI 并重启（双击启动器即可自动拉最新源码）。
2. 在桌面端体验「已关闭会话 → 导出上下文」，把对话交给下一个工具。
3. 手机连上远程终端，在 Android 镜像画面里试试“指哪打哪”。

**一句话介绍：DuoCLI——把多家 AI CLI 放进一个桌面，把对话和手感带到每一块屏幕上。**

## English

### Built for two small moments that used to waste your day

Everyone who juggles multiple AI coding CLIs knows the feeling: Claude builds half a feature, and you want Codex to finish it — so you copy, paste, scroll, and re-explain, like onboarding a brand-new teammate for three hours.

Or you are on the couch, phone connected to your home machine's terminal, and you spot the spot you want to tap — but your finger feels like it's behind glass.

v1.3.0 targets exactly those two moments.

### Android mirroring on your phone: see it, tap it, done

The mirrored screen is no longer just a live view. We rebuilt hit-mapping so that:

- **WYSIWYG**: whether you're watching the video stream or a screenshot, what you see is where your tap lands;
- **Forgiving targets**: a 16px button on screen gets a much larger practical hit area — no more missing by a hair;
- **Natural scrolling**: vertical scrolling and gestures stay in your thumb's muscle memory; only horizontal content is handed to the device.

### Cross-agent context transfer: switch tools, keep the memory

Every closed desktop session with conversation history now offers an **Export** action:

- One click exports the full Q&A history (parsed from each CLI's own output format);
- Open a clean, readable context viewer in your browser — user and AI turns clearly separated;
- Drag the exported JSON into Claude Code, Codex, Cursor, or any other CLI and pick up right where you left off.

**No more hand-copying dozens of lines between agents.**

### More CLIs, smarter resume

- **New: Qoder (qodercli) full-auto preset**, with automatic alias detection across command names;
- Resume capture upgraded across the board — Claude Code, Codex, Gemini, Kimi, Cursor, Antigravity, OpenCode, Kiro, Qoder… including JSON session IDs emitted by headless modes;
- CLI detection is pre-warmed in the background at startup, so opening “New Session” on your phone no longer stalls while the app checks every CLI you haven't installed.

### Mobile experience polish

- **Plan/schedule settings panel**: enable, disable, auto-approve permission prompts, and set the interval in minutes — all in one dialog;
- **Project file browser**: directory tree with filters for documents, media, and project files;
- **Cleaner Android views**: live screen and screenshot entries are easier to reach;
- **More terminal color themes**, shared between desktop and mobile.

### Remote access that stays up and stays yours

- **Resident Cloudflare guard**: a keep-alive supervisor probes and restarts the tunnel automatically — no more recurring 502 dropouts;
- **Close the window, keep the service**: closing DuoCLI no longer cuts your remote server; the phone stays connected;
- **Editable remote token**: the remote access token can now be edited and saved right in the desktop app.

### The launcher you'll actually use

Double-clicking the launcher now does the right three steps for you: **pull the latest source → quit the stale packaged build → start from the newest code**. No more “I updated, but it still runs the old version.”

### Quality

Unit tests **104/104** green — covering session resume, mirror protocols, PTY environment, file previews, and mobile regressions.

### Upgrade

1. Update and restart DuoCLI (the launcher pulls the latest source automatically).
2. On desktop, try “Closed Sessions → Export Context” and hand the conversation to your next tool.
3. Connect from your phone and tap the Android mirror — now it goes where you point.

**DuoCLI: one desktop for the AI CLIs you already use, with your conversation and your touch carried across every screen.**
