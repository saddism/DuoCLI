# 手机对话界面功能优化

日期：2026-09-30。范围：手机 PWA 原生对话视图（`native-chat-view.js`）的渲染与消息操作。终端滚动惯性见 `terminal-scroll-momentum-2026-09-30.md`。

## 改动

| 功能 | 行为 |
| --- | --- |
| 助手消息 Markdown 渲染 | 标题（#~######）、加粗、斜体、行内代码、无序/有序列表、引用、分隔线、段落；先转义再生成受限结构，原文不会变成 HTML。强调只在一行内闭合，失控的 `**` 不会吞掉整段；`_` 不参与斜体，`some_var_name`、路径不再被误判。用户输入保持原文（所见即所发） |
| 思考过程默认折叠 | `role: reasoning`（Claude 纯思考轮次、Codex/Grok reasoning）渲染为可展开的「思考过程 · N 字」，展开状态在轮询重渲染时由节点复用逻辑保留，不再淹没对话 |
| 复制全文 | 有文本的消息 meta 行出现「复制全文」，提取全部文本块（跳过工具输入/输出），成功后 toast 提示 |
| 跨天时间标注 | 今天之前的消息时间旁补上 `MM-DD`，长对话跨天不再混淆顺序；时间固定 24 小时制，不再依赖设备 locale |

渲染走原有的 key 差量复用（`id + role + occurrence`），轮询期间已展开的工具详情、选区不受影响；`white-space` 对 Markdown 消息改为 `normal`，由元素承载结构。
