# 公网与局域网线路选择

点击现有的 Wi-Fi / 云朵状态图标，打开「连接线路」面板：

- 自动切换：前台每 5 秒检查线路，恢复联网、切回前台、系统网络类型变化时也检查。公网模式下，局域网连续两轮通过带令牌的 `/api/network-check` 验证才切过去。局域网连续两轮失败时，先验证公网，再切回；回到公网后有 30 秒冷却，避免来回跳。
- 强制局域网：固定使用局域网，直到再次选择。手动选择可以在浏览器阻止探测时尝试跳转，但不把失败探测当作自动切换依据。
- 强制公网：固定使用公网，直到再次选择。手动选择没有 10 分钟自动失效。

切换前等待正在发送的消息完成，保留当前会话、输入草稿、聊天视图偏好和未确认消息的发送编号。状态通过带令牌的短期单次交接票据传递，不把草稿放进地址栏。源线路失效时，可以通过仍可达的目标线路保存状态；交接失败时保留原页面和草稿。重试未确认消息沿用原发送编号，后端不会重复执行。

自动切换等待输入法组合文字、发送动作和弹窗操作结束。手动切换期间暂时关闭发送入口；目标页面恢复会话后等待终端快照，再恢复发送。

`/api/lan-info` 返回当前局域网地址和已配置的公网地址。公网断开时可以使用缓存的局域网候选，但仍需实时验证。只有进入后台或系统已离线时停止探测；所有候选不可达时留在原页面等待恢复，不跳向一个未验证的旧 IP。

HTTPS 页面探测 HTTP 局域网受浏览器的本地网络权限限制，自动模式无法绕过用户拒绝的权限。Chrome 的相关限制见[官方说明](https://developer.chrome.com/blog/local-network-access?hl=zh-CN)。手动入口一直保留。
