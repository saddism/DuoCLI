# 终端复制操作条与斜杠命令临时切终端

日期：2026-09-30。范围：手机 PWA 终端选区复制、对话界面斜杠命令发送行为。

## 一、终端复制操作条

### 问题

- 之前版本移除了终端复制按钮，选区复制只挂在 DOM `copy` 事件上；xterm 画布选区
  不会唤起系统复制菜单，真机上长按选中后**没有任何可点的复制入口**（e2e 用合成
  ClipboardEvent 才能验证，掩盖了这一点）。
- 「复制当前屏」等兜底路径依赖 `navigator.clipboard.writeText`，失败后的
  `execCommand('copy')` 会触发 copy 事件，被终端选区监听器劫持成 xterm 选区文本，
  导致复制内容错误（本次「复制当前屏」e2e 即复现）。

### 改动

- 选中文字后出现浮动操作条 `#terminal-selection-bar`：「复制」（选区，TUI 视觉
  换行还原为自然段落）与「复制当前屏」（整屏行文本）；默认锚在选区终点下一行，
  端点滚出视口后贴上/下边——往上滚动阅读时复制仍然可达。选区清除即隐藏。
- 操作条位于终端手势守卫内（`#terminal-selection-bar`），点按钮不会触发滚动/
  选区手势；历史层可见时隐藏。
- 修复 copy 劫持：`execCommand('copy')` 兜底期间设置抑制标记，copy 监听器让路，
  由隐藏 textarea 原生复制正确文本。
- 「手机终端允许纵向滚动且没有复制按钮」「长按不另放复制按钮」两条旧断言更新为
  新语义：无选区时操作条隐藏、长按本身只选词不写剪贴板。

## 二、斜杠命令临时切终端

- 对话界面发送**任意** `/command` 形态输入（含白名单外的自定义技能如 `/init`、
  `/cost`、`/my-skill`）都不再产生乐观聊天气泡，发送成功后临时切到同会话终端看
  执行；会话视图偏好不变，终端顶部「对话」按钮即回。
- 新增 `slashCommandText()`：单行 `/name [args]` 即命令；文件路径（`/Users/...`）、
  多行输入、前导空格不在此列。菜单型命令（`/model` 等）保留原提示文案，
  其它命令提示「完成后点顶部对话返回」。
- 恢复未确认发送时同样跳过斜杠命令的本地气泡。
