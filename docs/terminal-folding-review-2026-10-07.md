## 问题与修复

| 问题 | 修复后的行为 |
| --- | --- |
| 工具后带缩进的段落、Markdown 标题和后续步骤可能被吞进工具详情 | 空行后优先保留普通正文；测试报告、补丁、工具错误和详情提示分别识别 |
| shell 和其他 CLI 工具折叠后看不到命令或文件 | 摘要保留命令/路径，长内容换行，退出码仍可见 |
| 展开状态随当前画面的节点消失；多个 Explored 记录容易串状态 | 保留同一终端最近 1000 条记录的展开状态，通用标题结合首条详情识别；引号内不同空格的命令保持独立 |
| 全部折叠改变内容高度，阅读位置跳动 | 单条操作和全部操作保留阅读锚点；内容已能全部放入视口时允许浏览器按实际滚动边界调整 |
| 连续滚轮事件跳过许多历史页；最新页仍接收 PageDown | 翻页限流，折叠后短暂抑制惯性翻页；向下翻页只在 Codex 历史状态触发 |
| 历史页只有正文时折叠层消失；局部重绘中光标在页脚时输入行判断失败 | 历史正文继续显示；在页脚区域寻找原生输入行，折叠层止于编辑器上方 |
| 普通宽终端被无工具的投影遮挡，破坏原生选字 | 无活动记录的普通终端保留原生 xterm；已有折叠记录的正文页仍保持阅读视图 |
| 历史片段容易被误认为完整会话，返回按钮覆盖首条记录 | 显示历史翻页提示；返回按钮位于提示栏内；不重复投影 Codex 的返回提示 |
| 跨物理行读取丢失分隔空格；销毁后留下折叠控件 | 拼接逻辑行后再去除末尾填充；销毁时清理控件、状态和刷新计时器 |

## 实际窗口与边界

通过 Electron 的 View → Reload 加载本地最终 renderer，主进程 PID 73831 保持运行，两个现有会话仍在。实际会话已核对全部展开/折叠、历史翻页提示、同一历史片段中的正文及顺序保留、长命令换行、原生输入区，以及最终按钮从历史回到最新。返回按钮与首条记录分行布局，不覆盖记录计数。

Codex 使用 alternate screen，历史仍由 Codex 分页提供。折叠层不把不连续的屏幕快照拼成虚假的完整历史，也不能恢复 CLI 自身以省略号或“ctrl+t to expand”隐藏的原文。折叠操作不会主动切换历史页；需要继续上/下滚动加载更早/更新片段。此处保证折叠过程保留当前可用内容与阅读状态，不声明所有历史已一次性载入。
